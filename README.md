# dimmer

macOS 菜单栏专注工具：当前窗口保持原样，其余窗口和桌面一直压暗。
开始一段专注就后台计时，时间到了全屏提示一下就淡出，休息和专注一样自己从菜单开始。

多显示器时每块屏各自保留一个亮窗口：焦点所在屏是焦点窗口，其他屏是各自最前面的窗口。

## 用法

- **专注**：菜单「Start Focus」或 ⌃⌥⌘F，时长在菜单「Focus」条里选（默认 40 分钟）。专注中菜单「Pause」暂停、「Resume」继续，暂停时倒计时停住，暂停的时间不算专注。
- **专注结束**：时间到，或菜单 / ⌃⌥⌘F 提前结束。之后菜单里是「Start Rest」。
- **休息**：菜单「Start Rest」或 ⌃⌥⌘F 开始，时长在菜单「Rest」条里选（默认 10 分钟）；菜单 / ⌃⌥⌘F 可提前结束，结束后回到空闲。
- **全屏提示**：只有专注或休息的倒计时自己走完时才出现（手动结束不出现）。所有屏幕（包括全屏 app）变暗，
  显示 `FOCUSED 40 MIN` 或 `RESTED 10 MIN`，约 2.5 秒后自己淡出；点一下立刻淡出。不抢键盘，打字照常进当前 app。
- **20-20-20 护眼提醒**：一直开着，不用专注也会提醒。连续看屏幕 20 分钟，用同样的全屏提示显示 `LOOK AWAY 20 SEC`（看 6 米外 20 秒），约 2.5 秒后淡出。下次提醒的倒计时在菜单顶部的内环。
  熄屏 / 睡眠、锁屏、切换用户、休息阶段都算休息过，结束后重新计 20 分钟；到点时如果已经 5 分钟没碰键盘鼠标（人不在），这次不提醒，直接开始下一个 20 分钟。
- **菜单**：点菜单栏图标或按 ⌃⌥⌘D 打开。顶部是两个同心半环（和分隔线一样宽）：外环是专注 / 休息进度（10 段），内环是下一次 20-20-20 提醒（20 段，一段 1 分钟）；环里显示阶段、倒计时 `38:12` 和 `EYE 12:34`，休息时护眼计时停在 `20:00`。专注结束、还没开始休息时显示 `DONE 40 MIN`。下面三条可点可拖的分段条，都是 20 段、上下对齐：「Focus」一段 5 分钟（5–100 分钟），「Rest」一段 1 分钟（1–20 分钟），「Dim」一段 5%（0%–100%，拖到最左是 0% 不压暗，100% 是纯黑）。改时长从下一轮生效，正在跑的这轮不变。
- **菜单栏图标**：和 app 图标同一构图（两个暗窗口 + 一个亮窗口）。平时三个窗口都是灰色，专注时中间那个亮起来，暂停时变回灰色。

## 构建

```bash
./build.sh
```

依次完成：`swiftc -O` 编译 → 拼装 `build/dimmer.app` → 签名 → 复制到 `~/Applications/dimmer.app` 并重启。

- App 图标由 `icon.swift` 绘制，只在该文件改动后重新生成（缓存在 `build/AppIcon.icns`）。菜单栏图标是同一构图的单色版，专注开始 / 结束时各画一次。
- 需要 Xcode Command Line Tools（`swiftc`），目标 macOS 14+，无第三方依赖。
- 签名用钥匙串里的自签名证书 **Dimmer Dev**；没有的话脚本会自动创建。
  第一次签名时系统可能弹窗询问 codesign 能否使用这个私钥：输入登录密码，选 **始终允许**。
- 证书不可用时退回 ad-hoc 签名，此时每次重新构建后都要重新勾选辅助功能。

## 设置

都在 `com.jayden.dimmer` 域里，改完重启 dimmer 生效：

```bash
defaults write com.jayden.dimmer focusHotKey "ctrl+opt+cmd+f"   # 开始 / 结束专注
defaults write com.jayden.dimmer menuHotKey  "ctrl+opt+cmd+d"   # 打开菜单
```

测试用的短时长可以用启动参数临时覆盖，不会写进设置：

```bash
open ~/Applications/dimmer.app --args -focusMinutes 0.1 -restMinutes 0.1   # 各 6 秒
open ~/Applications/dimmer.app --args -eyeMinutes 0.1                      # 20-20-20 提醒每 6 秒一次
```

## 授权

- **辅助功能**：用于跟随同一 app 内切换 / 新开 / 关闭窗口。首次启动会弹系统提示；
  没授权时菜单里有「Grant Accessibility Access…」。授权后自动生效，不用重启；用 Dimmer Dev 证书签名时重新构建不会失效。
- 没有授权也能用，只是只跟随「切换 app」。
- 快捷键和开机启动不需要额外权限。

## 已知问题

- **用了私有 API**，都通过 `dlsym` 动态加载，缺失时自动降级、不会崩溃：
  - `CGSCopyManagedDisplaySpaces` / `CGSAddWindowsToSpaces` 等：每个桌面 Space 放一个 overlay，全屏 Space 里不放。
    缺失时退回「一个 `.canJoinAllSpaces` overlay」，全屏 Space 靠「焦点窗口铺满屏幕」判断并隐藏，进出全屏可能闪一下。
  - `_AXUIElementGetWindow`：拿到真正的焦点窗口。缺失时用「前台 app 最上面的窗口」代替。
- 在 macOS 26 上，`canJoinAllSpaces` 的窗口即使不加 `.fullScreenAuxiliary` 也会出现在全屏 Space 里，所以改用每个桌面 Space 一个 overlay。
- 用 `.transient` 而不是 `.stationary`：`.stationary` 会让 overlay 在 Mission Control 里停在原处，盖住窗口缩略图。
  进出 Mission Control 时系统会对 overlay 做约 50 ms 的淡入淡出。
- **激活时序**：app 被激活的通知比它真正把窗口抬到最前早 50–250 ms。dimmer 在事件之后保持原画面，每帧（按最快那块屏的刷新率）查一次窗口层级，
  最多 0.7 s，等焦点窗口上方不再有别的 app 的窗口再一次性重排（同一 app 的窗口可以在上面，例如全屏 Safari 单独成窗的工具栏）。
  这是事件触发、有上限的短暂检查，空闲时不运行。
- **拖动窗口**时压暗层不动，松手 0.15 s 后才更新一次（例如拖到另一块屏）。
- 前台 app 被激活了却没抬起任何窗口（例如点击桌面时 Finder 的窗口留在后面），要等 0.7 s 后才隐藏 overlay。
- 第一次进入一个新建的桌面 Space 时，要等焦点窗口就位后才开始压暗。
- 非焦点屏上，不在前台的 app 关闭窗口时收不到事件，那块屏要等下一次切换才更新。
- 专注计时不跨重启：退出 dimmer 会丢掉当前这一轮。

## 资源占用

原则：不需要的时候什么都不做，需要的时候只在必要的时刻醒一次。

- **计时不走秒**：一轮专注或休息只有一个 wall-clock 一次性定时器，只在结束那一刻醒一次，留 1 s 余量让系统合并唤醒。
  用 wall clock，所以睡眠的时间也算进去，睡过头的话一唤醒就触发。
- **护眼提醒也只有一个一次性定时器**：用单调时钟（睡眠时不走），每 20 分钟醒一次，留 5 s 余量；熄屏、锁屏、休息时直接取消，回来再重新挂。
  判断「人在不在」只在到点时读一次系统空闲时间，不轮询。
- **拖窗口只更新一次**：拖动中每秒几十个移动事件，原先每个都要读一次窗口列表（约 0.7 ms），现在松手后只读一次。
- **菜单倒计时只在菜单打开时走**：视图在打开菜单时创建、关闭时销毁，期间每秒重画一次。菜单栏上不常驻倒计时。
- **全屏提示用完即毁**，淡出后把 malloc 释放了但还没还给系统的页交还（`malloc_zone_pressure_relief`），菜单关闭后同样处理。
- **没有提示音**：播一次系统音会加载 CoreAudio（约 5 MB、多 6 个线程），而且之后一直常驻。

实测（MacBook Air M2，macOS 26.6.2，内置屏单屏）。内存是 physical footprint，即活动监视器「内存」列；
CPU 和唤醒次数用 `top -stats cpu,idlew` 采样：

| 场景 | 结果 |
| --- | --- |
| 刚启动，空闲 30 s | 13 MB，CPU 0.0%，0 次唤醒 |
| 专注中，空闲 20 s | CPU 0.0%，0 次唤醒 |
| 切换 app 20 次 | 每次约 7 ms CPU |
| 窗口移动 40 次 | 共 20 ms CPU |
| 菜单打开、倒计时在走，10 s | CPU 0.3%，1 次唤醒 |
| 连续 10 轮专注 + 休息 | 11–13 MB 之间波动，不随轮数增长 |
| 加入 20-20-20 后，刚启动空闲 30 s | 9.6 MB，CPU 0.0%，0 次唤醒 |
| 护眼提示每 6 秒一次，连续弹 8 次 | 稳定 10 MB，不增长 |
| 可执行文件 | 349 KB |

- 内存大头是 AppKit 本身，以及 ColorSync 色彩转换表（每个约 1 MB，按「源色彩空间 × 屏幕 profile」缓存）。
  overlay 窗口用 device RGB 色彩空间，纯黑填充不需要色彩匹配，不会为每块屏建转换表。
- 和改版前的 Dimmer 1.1.4 相比（启动约 13 MB，切换 app 6–8 ms）：加了专注计时、全屏提示和菜单倒计时，占用基本持平。
